# Screenshots Directory

Add your application screenshots here:

- `landing.png` - Landing page screenshot
- `profile.png` - User profile page
- `admin.png` - Admin dashboard
- `tournaments.png` - Tournament management page

## Recommended Screenshot Sizes

- Width: 1920px or 1280px
- Format: PNG (for transparency) or JPG
- Use high-quality images
- Ensure no sensitive data is visible

## How to Take Screenshots

1. Open the application in your browser
2. Navigate to each page
3. Take screenshots (use browser dev tools for consistent sizes)
4. Optimize images (use tools like TinyPNG)
5. Save with appropriate names in this directory
